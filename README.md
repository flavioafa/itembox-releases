# ItemBox releases

Windows builds of ItemBox (`itembox.exe` and `itembox-gui.exe`), one GitHub release per version, each with a `SHA256SUMS` file.

ItemBox installs on each device check this repository for a newer version, verify the SHA-256 and keep the files in the user's box, so the other devices update from the box without downloading again.

The source code is not in this repository.
